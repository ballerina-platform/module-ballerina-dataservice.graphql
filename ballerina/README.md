# Ballerina Data Service GraphQL Library

## Overview

The `ballerina/dataservice.graphql` package is the GraphQL runtime of the data services that `bal persist` generates from a persist model. Generated GraphQL services call it to build errors, persist queries and auth checks, so fixes reach them without regeneration.

The design is in the [GraphQL data service proposal](https://github.com/ballerina-platform/ballerina-spec/issues/1520).
